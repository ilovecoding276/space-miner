# Space Miner

## Description
Space Miner is a browser-based arcade game where the player controls a spaceship and collects green minerals while avoiding dangerous red asteroids. The goal is to survive as long as possible and earn the highest score.

## How to Play
- Move the spaceship left and right
- Collect green minerals to gain points
- Avoid red asteroids or lose lives
- Survive as long as possible

## Controls
- Arrow Left = Move Left
- Arrow Right = Move Right

## Features
- Player movement
- Mineral collection system
- Asteroid obstacles
- Score tracking
- Lives system
- Game over screen

## Technology Used
- HTML
- CSS
- JavaScript
- HTML Canvas
